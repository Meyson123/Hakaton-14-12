# 🚚 AutoCargo: Беспилотный грузчик для промышленных предприятий

## 🌟 Концепция проекта
Система управления беспилотными грузчиками, где тележки определяют маршрут через компьютерное зрение, ориентируясь на светодиодные маркеры-столбы.

**Команда**: Дрон Спейс  
**Хакатон**: Сибирский Промышленный хакатон «Промка»

## 🧩 Что под капотом
- **CV-навигация**: Детекция светодиодных маяков в реальном времени
- **Сетевая архитектура**: Взаимодействие сервера управления и клиентов-тележек
- **Алгоритмы маршрутизации**: Оптимальные пути движения между цехами

## 💻 Ключевые модули
- `server.py`: Центр управления (маршрутизация, мониторинг)
- `client.py`: Логика тележки (движение, навигация)

## ⚙️ Технологии
- **Python 3.10**: Основной язык серверной и клиентской частей  
- **OpenCV**: Детекция светодиодных маяков и позиционирование  
- **pyA20**: Управление периферией тележки (моторы, датчики)  
- **Socket**: Сетевое взаимодействие тележек с сервером управления  

## 🏆 Преимущества реализации
- **Адаптивность**: Работа при разном освещении и рельефе
- **Минимальные задержки**: Быстрая передача команд
- **Безопасность**: Локальная сеть без внешнего доступа
- **Эффективная маршрутизация**: Оптимизация перемещений
